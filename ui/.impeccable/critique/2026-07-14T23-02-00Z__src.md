# What's Working

1. **Doc-neutral status palette** (`status-badge.tsx`): status uses a fixed semantic scale explicitly NOT recolored by `data-dfe-theme`, so "Autorizada" reads identically across all four doc types. Conscious, documented decision.
2. **Glossary via HTML Popover API** (`glossary-term.tsx`): top-layer render escapes form `overflow` clipping, works on touch (unlike `title`), anchor-positioning with fallback. Elegant fiscal-jargon solution.
3. **Per-type accent theme with a11y-correct override** (`dfe-theme.ts`): MDF-e maps `--brand-600` to amber-600 `#d97706` instead of spec `#f59e0b` because white-on-`#f59e0b` fails AA. Legibility-over-spec.

# Priority Issues

**[P1] Red text fails WCAG AA** — `text-red-500` (`products/page.tsx:127` Excluir, `cnpj-lookup-badge`) ~3.7:1 and `text-red-400` (`status-badge.tsx:52` info icon) ~3.0:1 fall below 4.5:1. Destructive/rejection cues are where a11y matters most on an eMAG-target product. Fix: standardize destructive text to `red-600`/`red-700`; consider a `text-danger` token. → `colorize`

**[P2] No global reduced-motion guard** — 40 `animate-pulse` skeletons/transitions keep animating for `prefers-reduced-motion` users; only `.gt-pop` + status dot opt out. Fix: global `@media (prefers-reduced-motion: reduce)` block zeroing animation/transition durations in `globals.css`. → `harden`

**[P2] Primary buttons violate 44px mobile touch target** — `Button` default `h-8` (32px); primary CTAs ("Novo produto", "Consultar SEFAZ") render 32px at 375px, under the CLAUDE.md 44px rule. Fix: `min-h-11 sm:h-8` on primary variant or `lg` size below `sm:`. → `layout`

**[P2] List tables force horizontal scroll on mobile** — `products` and `cte/distributions` set `minWidth=560`, scrolling at 375px; CLAUDE.md prefers card/list on mobile. Fix: `sm:` card renderer from existing row data, or drop minWidth below 375. → `layout`

**[P3] Inconsistent elevation/tokens** — Modal uses `shadow-xl` (`modal.tsx:104`) while config defines `shadow-modal`; stray `bg-gray-50/60`. Polish pass standardized tables, not modal elevation. → `polish`

**[P3] Landing is a generic long-scroll template** — `page.tsx` category-reflex SaaS brochure shape. Distill to hero + supported doc types + one trust block; move plans/roadmap below fold or to `/precos`. → `distill`
